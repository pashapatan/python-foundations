# Student Grade Calculator

A simple Python program that calculates a student's total marks, average, percentage, and grade based on marks in five subjects.

## Concepts Used

- Variables
- Data types
- User input
- Type conversion
- Arithmetic operations
- Conditional statements
- f-strings

## How It Works

1. Takes the student's name.
2. Takes marks for five subjects.
3. Calculates the total marks.
4. Calculates the average.
5. Calculates the percentage.
6. Assigns a grade based on the percentage.

## Grade Criteria

| Percentage | Grade |
|------------|-------|
| 91–100     | A+    |
| 81–90      | A     |
| 71–80      | B     |
| 61–70      | C     |
| 51–60      | D     |
| 0–50       | Fail  |
