# Shopping Bill Calculator

A simple Python program that calculates the total cost of a product after applying a discount.

## Concepts Used

* Variables
* Strings
* Integers
* Floats
* User input
* Type conversion
* Arithmetic operations
* f-strings
* Number formatting

## What I Learned

I learned how to work with different Python data types, convert user input into numbers, perform calculations, and format numerical output to two decimal places.

## How to Run

Run `main.py` and enter the product name, price, quantity, and discount percentage.
