# Pizza Order Calculator

This is a simple Python program that calculates the total price of a pizza based on the user's choices.

## What I practiced

* if, elif, and else
* Nested if statements
* Taking user input
* Variables
* Arithmetic operations
* String methods
* f-strings

## How it works

The program asks the user for:

* Pizza size: Small, Medium, or Large
* Pepperoni: Yes or No
* Extra cheese: Yes or No

Based on the choices, it calculates and displays the final bill.

## Pizza Prices

* Small: $15
* Medium: $20
* Large: $25

Pepperoni and extra cheese have additional charges depending on the selection.

## What I learned

I learned how to use multiple conditions together and how to calculate a final result based on different user choices.
