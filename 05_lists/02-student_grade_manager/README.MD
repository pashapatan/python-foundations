# Student Grade Manager

A simple Python program for managing student names and marks using lists.

## Concepts Learned

* Creating and working with lists
* List indexing
* Positive and negative indexing
* Updating list items
* "append()"
* "insert()"
* "remove()"
* "pop()"
* "index()"`
* "len()"
* "in" operator
* "for" loops
* "if" conditions
* "max()"
* "min()"
* "sum()"
* "sorted()"

## Features

* Display students and their marks
* Find the highest and lowest marks
* Calculate the average mark
* Count students scoring 80 or above
* Find the highest and lowest scorers
* Search for a student and display their mark
* Add a new student and mark
* Remove a student and their corresponding mark
* Sort the marks
* Display passed and failed students
