# Tip Bill Split Calculator

A simple Python program that calculates how much each person should pay after adding a tip to the total bill.

## Concepts Used

* Variables
* User input
* Data types
* Type conversion
* Arithmetic operations
* `round()`
* f-strings

## What I Learned

I learned how to take numerical input from  users, perform calculations using variables, and round the final result to two decimal places.

## How to Run

Run `main.py`, enter the total bill, choose a tip percentage, and enter the number of people sharing the bill.
