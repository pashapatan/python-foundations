# Password Generator

This is a simple Python program that generates a random password based on the number of letters, numbers, and symbols chosen by the user.

## What I practiced

* `random` module
* Lists
* `for` loops
* `range()`
* `random.choice()`
* `random.shuffle()`
* `append()`
* `join()`
* User input
* f-strings

## How it works

The program asks the user:

* How many letters they want
* How many numbers they want
* How many symbols they want

It then randomly selects the requested characters, shuffles them, and combines them into a final password.

## Example

```text
Welcome to the Password Generator!

How many letters would you like in your password?
6

How many numbers would you like?
2

How many symbols would you like?
2

Here is your final password: aP7!x2@Lm
```

## What I learned

I learned how to use the `random` module to select and shuffle items, how to work with lists, and how to convert a list of characters into a single string using `join()`.
