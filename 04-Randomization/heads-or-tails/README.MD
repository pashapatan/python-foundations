# Heads or Tails

A simple coin-toss guessing game built with Python.

## How It Works

The player chooses either **Heads** or **Tails**. The computer randomly generates the result of the coin toss and compares it with the player's choice.

* If the choices match, the player wins.
* If they don't match, the player loses.

## Concepts Practiced

* Randomization
* `random` module
* `random.choice()`
* User input
* String methods
* Variables
* Conditional statements
* Comparison operators

## How to Run

```bash
python main.py
```

## What I Learned

This project helped me practice Python's `random` module and understand how random choices can be combined with user input and conditional logic to create a simple interactive game.
